Với tiệm giặt là, sửa quần áo hay lắp đặt, khó chia chính xác vài trăm đồng nước/điện cho từng cái áo. Bạn cứ để Giá vốn = 0đ rồi lập phiếu chi tiền điện, nước, bột giặt cuối kỳ trong Sổ quỹ (tích Hạch toán KQKD) để báo cáo Lợi nhuận cuối tháng vẫn chuẩn xác.

Tuyệt đối không xóa hoặc đổi tên dòng tiêu đề file mẫu Excel

File mẫu Import của KiotViet ánh xạ dữ liệu theo đúng tên cột. Hãy copy dữ liệu cũ dán giá trị (Paste Values) vào các cột tương ứng, dùng đúng số 1 (Có) / 0 (Không) và lưu đuôi .xlsx chuẩn.
